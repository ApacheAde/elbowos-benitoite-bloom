# Benitoite Bloom

Full-colour Python 3 neon bloom pulse arcade for ElbowOS.

Expand a radiant pulse from the core to bloom orbiting crystals for points.

Space / Enter to pulse. R to restart.

## Play

```bash
pip install -r requirements.txt
python3 benitoite_bloom.py --play
```

## Record a 9:16 reel

```bash
python3 benitoite_bloom.py --record
```
